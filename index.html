Application Gestion Voitures

Cette application moderne utilise React 19 + TypeScript + Vite.
Les navigateurs web ne peuvent pas exécuter les modules TypeScript directement en ouvrant le fichier HTML en double-clic (file://).

// Commandes pour lancer l'application en local :
1. npm install
2. npm run dev
👉 Ouvrez dans votre navigateur : http://localhost:3000

Pour la version de production compilée : npm run build puis npm run preview.
